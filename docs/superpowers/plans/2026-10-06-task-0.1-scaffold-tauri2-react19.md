# Task 0.1: Scaffolding Monorepo Tauri 2 + React 19 + Tailwind v4 — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Inicializar o projeto desktop HelmADE com Tauri 2.x (Rust backend) e frontend React 19 / TypeScript / Vite com Tailwind CSS v4, incluindo janela principal com material translúcido nativo macOS e guardrails de qualidade de base.

**Architecture:** O monorepo segue a convenção Tauri padrão com `src-tauri/` para o backend Rust e `src/` para o frontend React. O Vite serve o frontend em dev e produz o bundle para o Tauri empacotar. O Tailwind v4 usa o plugin Vite nativo (`@tailwindcss/vite`) sem ficheiro de configuração separado, com design tokens Apple HIG definidos em `src/index.css`.

**Tech Stack:** Tauri 2.x · Rust (stable toolchain) · React 19 · TypeScript 5.x · Vite 6.x · Tailwind CSS v4 · `@tailwindcss/vite` · `tauri-plugin-dialog`

**Spec:** `docs/ROADMAP.md` § Task 0.1 · `PRD.md` § 5 (UX & Design) · `docs/project-brain.md` § 2 (Invariantes)

## Global Constraints

- Tauri >= 2.0 (não 1.x); usar `tauri-cli` via `cargo tauri`
- React 19 (não 18); usar o renderer concorrente
- Tailwind CSS v4; plugin `@tailwindcss/vite`; sem `tailwind.config.js` separado
- TypeScript strict mode (`"strict": true`)
- `cargo check` e `npm run build` devem passar a verde antes do commit
- Janela principal: sem decorações nativas (`decorations: false`), título `"HelmADE"`, tamanho inicial 1280×800, mínimo 960×600
- Fundo da janela: `vibrancy: "under-window"` (macOS) + `transparent: true`
- Tipografia: `font-family: 'SF Pro Text', system-ui, sans-serif` no CSS base
- Sem `git stash` em qualquer etapa
- Commits em Conventional Commits 1.0.0 (`chore(scaffold): ...`)

## Review Focus

1. **Vibrância macOS em modo escuro:** O efeito `vibrancy` pode renderizar a branco em Light Mode sem o CSS complementar `backdrop-blur`; o teste de smoke deve confirmar que a janela não é opaca.
2. **Versão do plugin Tauri desatualizada:** `tauri-plugin-dialog` deve ser compatível com a versão major de Tauri 2 usada — verificar `Cargo.lock` após `cargo check`.
3. **Tailwind v4 sem `content` glob:** O v4 faz auto-discovery de classes via Vite plugin; se o diretório `src/` estiver fora da raiz padrão detetada, as classes podem desaparecer no build de produção. → Task 3, verificar output de `npm run build`.
4. **`strict: true` vs. imports de tipos React 19:** O novo pacote `react-dom/client` tem tipos diferentes do 18 — garantir que `createRoot` não levanta TS2345. → Task 2, step de typecheck.
5. **Permissões Tauri 2 granulares:** O `tauri.conf.json` v2 exige declaração explícita de `permissions` por plugin; omitir `dialog:default` faz o comando de seleção de pasta falhar silenciosamente. → Task 4, smoke test.

- [ ] **Step 1: Criar `src/index.css` com tokens Apple HIG**

```css
@import "tailwindcss";

@theme {
  /* Apple HIG Color Tokens */
  --color-sf-primary: rgba(255, 255, 255, 0.92);      /* texto primário dark mode */
  --color-sf-secondary: rgba(255, 255, 255, 0.6);     /* texto secundário */
  --color-sf-tertiary: rgba(255, 255, 255, 0.36);     /* texto terciário */
  --color-sf-separator: rgba(255, 255, 255, 0.15);    /* separadores */
  --color-sf-fill: rgba(255, 255, 255, 0.08);         /* fills de superfícies */
  --color-accent-blue: #0a84ff;                        /* azul sistema macOS */
  --color-accent-gold: #ffd60a;                        /* dourado Orquestrador */
  --color-accent-green: #30d158;                       /* verde sucesso */
  --color-accent-red: #ff453a;                         /* vermelho erro */
  --color-accent-purple: #bf5af2;                      /* roxo QA */

  /* SF Pro Typography Scale */
  --font-sf: 'SF Pro Text', 'SF Pro Display', system-ui, -apple-system, sans-serif;

  /* Spacing */
  --radius-macos: 10px;
  --radius-macos-lg: 14px;
}

* {
  box-sizing: border-box;
  -webkit-font-smoothing: antialiased;
  -moz-osx-font-smoothing: grayscale;
}

body {
  margin: 0;
  font-family: var(--font-sf);
  background: transparent;  /* permite vibrância nativa macOS */
  color: var(--color-sf-primary);
  /* ponytail: fundo transparente depende de vibrancy Tauri; upgrade: adicionar fallback #1c1c1e para não-macOS */
}

/* Prevenir seleção de texto em elementos UI (comportamento nativo macOS) */
[data-tauri-drag-region] {
  -webkit-app-region: drag;
  user-select: none;
}
```
