# Task 1.3: Gestor de Git Worktrees e Criação Isolada de Grelhas (Módulo 2) — Implementation Plan

> **For agentic workers:** REQUIRED SKILLS: `rust-patterns`, `using-git-worktrees`, `error-handling`, `safety-guard`.

**Goal:** Implementar o motor de ciclo de vida de Git Worktrees em Rust para criar diretórios isolados por enxame (`.helm/worktrees/<id>`), gerir ramos dedicados (`helm/swarm-<id>`), listar worktrees ativos e efetuar limpeza segura no encerramento da grelha, assegurando o Invariante de Concorrência Segura (Zero Corrupção de Código).

**Tech Stack:** Rust (`std::process::Command`, zero deps extras) · Tauri 2.x Invoke API · TypeScript

**Spec:** `docs/ROADMAP.md` § Task 1.3 · `docs/adr/2026-10-06-0002-git-worktree-symlink-isolation.md`

## Global Constraints
- Proibição absoluta de `git stash` e `git stash pop`.
- Sanitização rigorosa de nomes de swarm para prevenir ataques de path traversal.
- Testes de integração em repositório temporário isolado (`std::env::temp_dir()`).
