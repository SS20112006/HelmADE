# Task 1.1: Persistência Local em SQLite & Gestão de Projetos — Implementation Plan

> **For agentic workers:** REQUIRED SKILLS: `schema-and-db-migration`, `rust-testing`, `error-handling`.

**Goal:** Implementar o motor de armazenamento local SQLite em Rust (`rusqlite`) com WAL mode, pragmas de isolamento e integridade, migrações automáticas de esquemas para projetos, sessões e grelhas, e expor comandos Tauri e cliente TypeScript correspondentes.

**Tech Stack:** Rust · `rusqlite` (bundled) · Tauri 2.x Invoke API · TypeScript · React 19

**Spec:** `docs/ROADMAP.md` § Task 1.1 · `docs/project-brain.md` § 2

## Global Constraints
- Custo 0.00€ absoluto (SQLite local embutido).
- PRAGMAs obrigatórios: `WAL`, `foreign_keys = ON`, `busy_timeout = 2000`.
- Zero vazamento de caminhos brutos em erros públicos de IPC.
- Testes unitários com banco in-memory validando idempotência de UPSERT e deleção em cascata.
