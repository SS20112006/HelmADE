# Task 1.6: Interface de Revisão e Fusão Segura (Diff & Merge View) (Módulo 2) — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Desenvolver o motor Rust de inspeção de Git Diff e fusão de worktrees (`squash` e `rebase`), acompanhado pela interface frontend de revisão (`MergeReviewView`), visualizador de diff sintático com estatísticas (`DiffViewer`), resolução de conflitos (`MergeConflictResolver`) e hook reativo (`useGitDiff`), garantindo fusão atómica sem corrupção do branch principal.

**Architecture:**
- Backend: Módulo nativo Rust `src-tauri/src/git/diff.rs` implementando extração de diffs por ficheiro (`git diff --name-status` e `--numstat`), obtenção de patch unificado por ficheiro (`git diff -U3`), motor de fusão com suporte a Squash e Rebase, deteção preventiva de conflitos e abortamento seguro.
- Comandos Tauri IPC em `src-tauri/src/commands/worktree.rs`: `get_worktree_diff`, `get_file_diff`, `merge_worktree`, `abort_merge`.
- Frontend: Contratos em `src/types/diff.ts`, cliente IPC em `src/services/gitDiffService.ts`, hook reativo `src/hooks/useGitDiff.ts`, visualizador de código `src/components/DiffViewer.tsx`, painel de aviso de conflitos `src/components/MergeConflictResolver.tsx`, e ecrã de revisão modal com materiais macOS `src/views/MergeReviewView.tsx`.

**Tech Stack:** Rust (`std::process::Command`, `serde`) · Tauri 2.x Invoke API · TypeScript · React 19 · Tailwind CSS v4 · Apple HIG Semantic Tokens

**Spec:** `docs/ROADMAP.md` § Task 1.6 · GitHub Issue #19 / #9

## Global Constraints
- Proibição absoluta de `git stash` e `git stash pop`.
- Conformidade estrita com Apple HIG: tipografia SF Pro Text (`<=19pt`) com tracking ótico vs SF Pro Display (`>=20pt`), contraste WCAG 2.1 AA mínimo (4.5:1), touch targets mínimos de 44x44px.
- Fusão Segura: em caso de conflito durante a fusão, o sistema deve abortar automaticamente a operação no Git (`git merge --abort` / `git rebase --abort`) para nunca deixar o repositório em estado instável ou deturpado.
- Sanitização de argumentos: identificadores de swarm e nomes de branch devem ser sanitizados para prevenir injeção de comandos na shell.
- Zero novas dependências npm externas (SVGs inline e Tailwind v4).
- Commits atómicos em formato Conventional Commits 1.0.0.

## Review Focus
1. **Accurate Diff Parsing**: Deteção correta de ficheiros adicionados (`A`), modificados (`M`), apagados (`D`) e renomeados (`R`), com contagem exata de linhas inseridas e removidas.
2. **Conflict Trapping**: Se um ficheiro tiver conflito na fusão com o branch principal, o Git é imediatamente abortado/limpo e a lista de conflitos é devolvida ao utilizador.
3. **Squash & Rebase Execution**: Suporte tanto a `Squash & Merge` com mensagem de commit convencional configurável, como a `Rebase Merge`.
4. **Visual Ergonomics & Taste**: Visualizador de diff fluido com distinção clara de cores (verde esmeralda para adições, vermelho suave para remoções, números de linha em SF Mono), sem layout slop.
5. **Clean Cancellation**: Fechar a janela ou clicar em cancelar não deixa ficheiros de lock nem resíduos no repositório.

**Interfaces:**
- Consumes: `std::process::Command`, `std::path::Path`, `serde::Serialize`, `serde::Deserialize`
- Produces:
  ```rust
  #[derive(Debug, Serialize, Deserialize, Clone, PartialEq, Eq)]
  pub struct DiffFile {
      pub path: String,
      pub old_path: Option<String>,
      pub status: String, // "added", "modified", "deleted", "renamed"
      pub additions: usize,
      pub deletions: usize,
      pub binary: bool,
  }

  #[derive(Debug, Serialize, Deserialize, Clone, PartialEq, Eq)]
  pub struct DiffSummary {
      pub swarm_id: String,
      pub branch: String,
      pub base_branch: String,
      pub files: Vec<DiffFile>,
      pub total_files: usize,
      pub total_additions: usize,
      pub total_deletions: usize,
  }

  #[derive(Debug, Serialize, Deserialize, Clone, PartialEq, Eq)]
  pub struct FileDiffDetail {
      pub path: String,
      pub patch: String,
  }

  #[derive(Debug, Serialize, Deserialize, Clone, PartialEq, Eq)]
  pub struct MergeResult {
      pub success: bool,
      pub strategy: String,
      pub merged_branch: String,
      pub target_branch: String,
      pub commit_sha: Option<String>,
      pub conflicts: Vec<String>,
      pub message: String,
  }

  pub fn get_worktree_diff(repo_path: &str, swarm_id: &str, base_branch: Option<&str>) -> Result<DiffSummary, String>;
  pub fn get_file_diff(repo_path: &str, swarm_id: &str, file_path: &str, base_branch: Option<&str>) -> Result<FileDiffDetail, String>;
  pub fn merge_worktree(repo_path: &str, swarm_id: &str, strategy: &str, commit_message: Option<&str>, base_branch: Option<&str>) -> Result<MergeResult, String>;
  pub fn abort_merge(repo_path: &str) -> Result<bool, String>;
  ```

    deletions: number;

    strategy: string;
    merged_branch: string;
    target_branch: string;
    commit_sha?: string | null;
    conflicts: string[];
    message: string;
  }

  export const gitDiffService = {
    getWorktreeDiff(repoPath: string, swarmId: string, baseBranch?: string): Promise<DiffSummary>;
    getFileDiff(repoPath: string, swarmId: string, filePath: string, baseBranch?: string): Promise<FileDiffDetail>;
    mergeWorktree(repoPath: string, swarmId: string, strategy: MergeStrategy, commitMessage?: string, baseBranch?: string): Promise<MergeResult>;
    abortMerge(repoPath: string): Promise<boolean>;
